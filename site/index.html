CPZ

An operating system for the CardputerZero handheld that opens a terminal instead of a desktop. Work in tabs, change settings from one menu, and open graphical apps when you need them.

Download image

Why CPZ

  1. Fast and light

    Starts quickly and uses little memory, leaving more for your apps.

  2. Terminal as desktop

    Tabs, panes and a status bar replace windows and icons.

  3. Keyboard control

    Every action has a key. A mouse is optional.

  4. Convenience first

    Plug in a drive and it opens in a tab; one search finds apps, files and settings.

  5. Graphical apps

    Games, video players and other graphical apps open over the terminal; close one and you are back in the same tab.

  6. Multiple languages

    Switch the interface and system language in Settings. No reinstall needed.

Install

  1. Download the image file from Releases.
  2. Write it to a microSD card with Raspberry Pi Imager, balenaEtcher or M5 Imager. This erases everything on the card.
  3. Put the card in and turn the device on. The first start takes a little longer.

All releases

First start

  • Log in with the name cpz and the password cpz, then set a new password in Settings → System → Security.
  • Turn on Wi-Fi in Settings → Connections. It is off by default.
  • Power off from Settings → Power. Don't unplug the device to turn it off.

Keys

Hold Alt and press a key. You can change any shortcut in Settings → Input → Shortcuts.

Alt+SOpen Settings
Alt+HShow this key list
Alt+Shift+Tab / Alt+TabSwitch to the previous / next tab
Alt+1…9Jump to tab 1–9
Alt+TOpen a new tab
Alt+WClose the current tab (asks first)

Alt+LShow all tabs
Alt+VSplit the screen into left and right panes
Alt+BSplit the screen into top and bottom panes
Alt+N / PSwitch to the next / previous pane
Alt+ZZoom the current pane; press again to undo
Alt+XClose the current pane
Alt+CCopy text from the screen
Alt+YPaste the last copied text
Alt+SpaceSwitch the keyboard layout
Alt+DSwitch between the built-in screen and automatic output
Alt+G / MMake the text bigger / smaller (the size is saved in Settings)
Alt+U / IRaise / lower the volume
Alt+0Mute or unmute the sound
