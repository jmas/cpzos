CPZ

A Linux for the CardputerZero handheld that starts in a text terminal instead of a desktop. Open tabs, split the screen, connect Wi-Fi and change settings — all from the keyboard.

Download image Install

Why CPZ

  1. It starts in a terminal

    No desktop to load. The terminal opens at boot, and Settings is a menu you drive with the arrow keys.

  2. Your work stays open

    Change settings or plug in an HDMI monitor without losing your tabs, split screens or running programs.

  3. Everything is in Settings

    Wi-Fi, Bluetooth, sound, display, power and apps live in one place. No config files and no extra setup tools.

Install

One image, one microSD card, no setup wizard. The image is built for the CardputerZero hardware.

  1. Download the .img.xz file from Releases.
  2. Write it to a microSD card with Raspberry Pi Imager, balenaEtcher, dd or M5 Imager. Writing erases the card.
  3. Insert the card and power on. The first boot takes a little longer than later boots.

The release page lists the SHA-256; check it before writing.

First boot

  • Log in as cpz / cpz, then set a new password in Settings → System.
  • Turn on Wi-Fi in Settings → Connections. It is off by default.
  • Power off from Settings → Power. Do not pull the power.
  • Plug in a USB drive; it opens in a new tab under /media.

Keys

Hold Alt and press the key. This is the short list; Alt+H on the device shows every binding, including copy, paste and tab selection. Every shortcut can be reassigned in Settings → Keyboard → Shortcuts.

Alt+A / FSwitch to the previous / next tab
Alt+TOpen a new tab
Alt+WClose the current tab (asks first)
Alt+VSplit the screen left / right
Alt+BSplit the screen top / bottom
Alt+N / PSwitch to the next / previous pane
Alt+ZZoom the current pane (press again to restore)
Alt+OSearch commands, files and apps
Alt+SOpen Settings
Alt+HShow this key list
Alt+DForce the built-in screen / return to automatic
Alt+G / MMake the text bigger / smaller (saved in Settings)
Alt+U / IRaise / lower the output volume
Alt+0Mute or unmute the output
Alt+QHide the session; log in again to return

Settings

Change Wi-Fi, Bluetooth, sound, display and power with the arrow keys and Enter. Alt+S opens Settings at any time.

SectionWhat you can do
ConnectionsJoin Wi-Fi, pair Bluetooth devices, check Ethernet and manage VPNs and addresses
DisplayTheme, brightness, screen timeout, text size, status bar and display output
SoundVolume, mute, input and output device
KeyboardKeyboard mapping, layouts, shortcut rebinding and the key list
Date & TimeDate, time, time zone and automatic clock sync
PowerBattery status, restart, shut down and suspend
ApplicationsBrowse, install and remove terminal apps
SystemAbout, system monitor, diagnostics, password, remote access (SSH) and reset

Help
