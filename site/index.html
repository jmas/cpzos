CPZ

A console-first Linux for the CardputerZero handheld. It boots straight into a fast terminal with a persistent tmux session — no desktop, compositor or background services.

Minimal memory footprint. Simple to install from a release image. Simple to use from the keyboard.

01

Philosophy

CPZ is built around a small set of rules. They decide what goes into the image, what a key does, and what the system refuses to do in the background.

  1. The terminal is the interface

    There is no desktop, compositor, launcher or first-boot wizard. kmscon draws the console on tty1, tmux organizes the work, and every other tool is a command.

  2. Minimal memory

    No desktop environment, no search index and no maintenance daemons. Everything that is not in use is not running, so RAM and CPU stay free for the work at hand.

  3. Simple to install

    Download the latest release image, write it to a microSD card with Raspberry Pi Imager, balenaEtcher or dd, insert it and boot. No manual package setup is required.

  4. Simple to use

    The keyboard drives everything. Alt shortcuts open tabs, panes, search and Settings, and the Settings TUI manages Wi-Fi, display, sound, power and applications without config files.

  5. State survives

    tmux runs detached. Theme, font and output changes may restart kmscon while tabs, pane directories and running programs stay alive.

02

Install

CPZ ships as a ready-to-flash Raspberry Pi OS image. Every release includes the image, its checksums and metadata.

  1. Download the latest image from the Releases page.
  2. Write it to a microSD card with Raspberry Pi Imager, balenaEtcher or dd.
  3. Insert the card and power on. CPZ boots straight into the console with no setup wizard.

Images are built from a published GitHub release and verified before upload.

03

Key reference

Every binding below works directly: press Alt with the listed key. No tmux prefix is needed. On the internal keyboard, plus and minus are Sym+T and Sym+R.

Alt+← / →Previous / next tab
Alt+TNew tab, inserted before Settings
Alt+WClose tab (asks first)
Alt+VSplit left / right
Alt+BSplit top / bottom
Alt+OSearch everything
Alt+SOpen Settings
Alt+HOpen this key reference
Alt+DToggle auto / panel display
Alt++ / −Larger / smaller font, saved in Settings
Alt+QDetach from tmux

04

Settings

Alt+S opens a full-screen TUI. It is always the last tab and cannot be closed; the shell is always the first. Values are stored per user and reapplied at boot.

PageControls
NetworkWi-Fi (NetworkManager TUI), Ethernet status, VPN profiles, addresses
BluetoothPair and connect Bluetooth devices
Display & BrightnessTheme, brightness, screen timeout, output mode, font size, status bar
SoundOutput and input volume, mute and device selection (PipeWire)
KeyboardLayout mode, enabled layouts, active layout, key reference
Date & TimeDate, time, time zone, automatic NTP
PowerBattery status, reboot, shut down, suspend
ApplicationsTerminal Trove catalog; install and remove apt packages
SystemAbout, resources, security (password, SSH), terminal options, reset
