CardputerZero · Raspberry Pi OS (Debian 13)

CPZ

A Linux for the CardputerZero handheld that starts in a text terminal instead of a desktop. Open tabs, split the screen, connect Wi-Fi and change settings — all from the keyboard.

This is a terminal system, not a desktop. Default login: cpz / cpz. Wi-Fi is off until you enable it in Settings.

01

Why CPZ

Three things make CPZ different from a desktop Linux.

  1. It starts in a terminal

    There is no desktop to load. The terminal opens at boot, and Settings is a menu with arrow keys — not a config file.

  2. Your work stays open

    Change settings or plug in an HDMI monitor without losing your tabs, split screens or running programs.

  3. Everything is in Settings

    Wi-Fi, Bluetooth, sound, display, power and apps are managed in one place. No config files, no extra setup tools.

02

Install

One download, one microSD card, no setup wizard. The image is based on Raspberry Pi OS and fits the CardputerZero hardware.

  1. Download the .img.xz file from Releases. You do not need the source code.
  2. Write it to a microSD card with Raspberry Pi Imager, balenaEtcher, dd or M5 Imager. Writing erases the card.
  3. Insert the card and power on. The first boot takes a little longer than later boots.

The release page lists the image size and checksum.

First 5 minutes

  • Log in as cpz / cpz, then set a new password in Settings → System.
  • Turn on Wi-Fi in Settings → Network. It is off by default.
  • Power off from Settings → Power. Do not pull the power.
  • Press Alt+H for the key list and Alt+O to search.
  • Plug in a USB drive; it opens in a new tab under /media.

03

Key reference

Hold Alt and press the key. The same list is on the device: Alt+H. On the internal keyboard, plus and minus are Sym+T and Sym+R.

Alt+← / →Switch to the previous / next tab
Alt+TOpen a new tab
Alt+WClose the current tab (asks first)
Alt+VSplit the screen left / right
Alt+BSplit the screen top / bottom
Alt+N / PSwitch to the next / previous split
Alt+ZZoom the current split (press again to restore)
Alt+OSearch commands, files and apps
Alt+SOpen Settings
Alt+HShow this key list
Alt+DForce the built-in screen / return to automatic
Alt++ / −Make the text bigger / smaller (saved in Settings)
Alt+QHide the session; log in again to return

04

Settings

Change Wi-Fi, Bluetooth, sound, display and power with the arrow keys and Enter. Settings opens in the last tab and stays available.
